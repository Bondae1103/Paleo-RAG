# Phase P4 Report — UniProtKB ↔ RCSB PDB Authoritative Mapping

## Done (with evidence)
- **Authoritative Mapping Pipeline Established**:
  - Queried PDBe SIFTS REST API (`https://www.ebi.ac.uk/pdbe/api/mappings/all_isoforms/{accession}`) for all staged proteins with PDB cross-references.
  - Parsed chain-level properties (`Method`, `Resolution`, `Chains`) directly from cached raw UniProtKB JSON entries.
  - Created `data/paleo_metadata.db:protein_structure_mappings` supporting full 1:N structure relationships per protein and M:N complex links.
  - Stored 2,699 total protein-structure mapping rows in SQLite.
- **Residue-Level Range Mapping**:
  - 2,658 / 2,699 mappings (98.5%) contain exact segment residue ranges (`uniprot_start`, `uniprot_end`, `pdb_start`, `pdb_end`) directly from authoritative PDBe SIFTS.
  - Woolly Mammoth Hemoglobin alpha (`D3U1H8`) mapped across 3 conformations (`3VRE`, `3VRF`, `3VRG`) with full chain coordinates (`2..142 <-> 1..141`).
  - Woolly Mammoth Hemoglobin beta (`D3U1H9`) mapped across 3 conformations (`3VRE`, `3VRF`, `3VRG`) with full chain coordinates (`2..147 <-> 1..146`).
  - Neanderthal ADSL (`A0A384E0N4`) mapped across 3 crystal structures (`5NX8`, `5NX9`, `5NXA`) across all chains (`A-H`, `1..487 <-> 1..487`).
- **Taxon Mismatch Detection**:
  - Compared protein organism TaxID against PDB structure source organism TaxID for every link.
  - Evaluated and classified:
    - `MATCH`: 2,659 mappings (98.5%)
    - `TAXON_MISMATCH`: 40 mappings (1.5%) where structures used proxy/homologous organisms or engineered constructs.
- **Live Independent API Verification Gate**:
  - Selected a random sample of 100 mapping pairs (seed=42).
  - Executed independent live REST queries against UniProtKB and RCSB PDB APIs.
  - Verified 100 / 100 pairs (100.0% pass rate). Zero discrepancies detected.
- **Verification Deliverables**:
  - Created `docs/verification/p4_mapping_verification_report.json`.
  - Machine-readable changelog at `data/changelogs/p4_mapping_changelog.jsonl` (2,699 rows).
  - Registered PDBe SIFTS API in `docs/DB_REGISTRY.md:Section 5`.
