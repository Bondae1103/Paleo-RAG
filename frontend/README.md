# PaleoDB Frontend

React 19 single-page application built with Vite, Tailwind CSS, and shadcn/ui components.

## Available Views

- **Taxa Atlas & Registry**: 18 prehistoric taxa with morphological records, extant alignments, 3D Mol* structures, and PBDB stratigraphic occurrences.
- **Sequence Workbench**: IUPAC validation, sequence format conversions (FASTA, GenBank, EMBL), six-frame translations, and INSDC submission metadata checking.
- **BioDB Multi-Explorer**: Federated query interface across NCBI, UniProt, RCSB, KEGG, Ensembl, and the Paleobiology Database.
- **Literature Copilot**: Grounded question answering with dual-pane passage inspection and chunk-level citations.

## Development

```bash
npm install
npm run dev
```

Build for production:

```bash
npm run build
```
