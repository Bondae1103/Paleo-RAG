# Phase P6 Report — Exhaustive Literature Search & Evidence Linking

## Done (with evidence)
- **Database Registry Expanded (§P6.1)**:
  - Added Section 11 to `docs/DB_REGISTRY.md` registering NCBI PubMed E-utilities (`esearch`, `esummary`, `efetch`) with documented parameters and empirical test call (`PMID:20448178` -> 200 OK).
  - Added Section 12 to `docs/DB_REGISTRY.md` registering Europe PMC REST API (`/search`, `/article/PMC/{id}`) with documented parameters, query syntax, and empirical test call (`PMID:20448178` -> 200 OK).
- **Literature Search Protocol Codified (§P6.1, §P6.2)**:
  - Created `docs/LITERATURE_SEARCH.md` establishing the evidence tier taxonomy:
    - Tier A: `uniprot_citation`, `pdb_primary_citation`, `xref_link`.
    - Tier B: `keyword_search_validated`.
  - Enforced short gene symbol disambiguation rule: gene symbols $\le 4$ characters (e.g. `D`, `HBA`, `HA`, `NP`) must co-occur with full protein name or taxon cue. Solitary short gene symbols are rejected.
  - Specified automated title/abstract text verification protocol with token and character offset tracking.
- **Relational Literature Tables Populated (§P6.3)**:
  - Initialized `data/paleo_metadata.db:papers` storing 885 distinct papers with title, journal, year, abstract, licensing, PMCID, DOI, retraction status, and raw response references.
  - Initialized `data/paleo_metadata.db:protein_paper_links` storing 8,438 links with `evidence_type`, `status`, `matched_strings_json`, `query_used`, and `reason_code`.
- **Open-Access Licensing Compliance (Decision H8)**:
  - Enforced approved Decision H8: abstracts stored for all papers; full-text JATS XML downloaded and stored in `data/processed/pmc_oa/` for 443 open-access papers (PMC Open Access subset, CC-BY, CC0, CC-BY-NC).
  - Stored explicit `license` field on every paper record (`Open Access (PMC / CC)` vs `Abstract only / All rights reserved`).
- **Exhaustiveness & Coverage Proof (§P6.4)**:
  - Produced `data/literature/coverage.csv` covering all 5,626 staged proteins across all 18 taxa.
  - Logged queries run, raw hit count, Tier A links, Tier B accepted, rejected, pending, and total valid papers.
  - Transparently identified 1,005 proteins with zero literature citations (unstudied hypothetical TrEMBL translations in extinct and microbial lineages; no padding per Directive 2).
- **Live Retrieval Integrity & Precision Audit**:
  - Retrieval integrity test: 100 / 100 (100.0%) stored papers re-fetched live from NCBI PubMed with matching titles.
  - Precision audit: random sample of 50 accepted Tier B links (seed=42) evaluated with character offset and term verification: 50 / 50 (100.0%) verified accurate.
  - Audit checklist delivered in `docs/verification/p6_precision_audit_sample50_seed42.json`.
