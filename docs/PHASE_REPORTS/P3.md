# Phase P3 Report — UniProtKB & RCSB PDB Bulk Pull into Staging

## Done (with evidence)
- **Bulk Pull from UniProtKB REST API**:
  - Queried official endpoint `https://rest.uniprot.org/uniprotkb/search` using cursor-based pagination.
  - Implemented polite rate-limiting, bounded retry logic with exponential backoff, and SHA-256 disk-caching of every raw response page in `data/raw_cache/uniprot/<tax_code>/`.
  - Stored 5,626 total protein records into SQLite `staging_proteins`.
- **RCSB PDB Structure Pull**:
  - Queried RCSB PDB Search API (`https://search.rcsb.org/rcsbsearch/v2/query`) using taxonomy lineage operator for each taxon.
  - Retrieved entity-level metadata (`/core/polymer_entity/{pdb_id}/{entity_id}`) and entry-level metadata (`/core/entry/{pdb_id}`).
  - Applied optimization cap for *Yersinia pestis* (25 polymer entities) and targeted 1918 historical query for *Influenza A* (25 polymer entities) to prevent downloading modern laboratory isolates.
  - Stored 60 polymer entities into SQLite `staging_structures`.
- **Count Reconciliation**:
  - Recorded `x-total-results` header on page 1 of every UniProt query and asserted that stored counts exactly equal reported counts across 100% of the 18 taxa. Zero count mismatches.
- **Explicit Species Attribution**:
  - Captured all matching species under multi-species prehistoric clades per human instruction:
    - *Smilodon* (`PRAG-TAX-010`): pulled both *S. fatalis* and *S. populator* (4 entries).
    - Glyptodont (`PRAG-TAX-016`): pulled across *Doedicurus* and *Glyptodon* (29 entries).
    - Moa (`PRAG-TAX-018`): pulled across all 13 recognized extinct moa taxa in order *Dinornithiformes* (55 entries).
  - Explicitly recorded `organism_name`, `organism_tax_id`, and `project_tax_code` on every single staged protein record.
- **Taxa Registry Scope Updates**:
  - Added `included_species` and `scope_note` columns to `taxa` table in SQLite.
  - Enriched `backend/data/paleo_atlas_registry.json` and `frontend/client/src/lib/paleo_atlas_registry.json` with multi-species lineage listings and clade scope notes.
- **UI Taxa Entry Page Overhaul**:
  - Added prominent **Taxonomic Clade Scope & Represented Species** dossier section to `TaxaAtlasView.tsx` detail modal, displaying scope notes and scrollable tag chips of all included species.
  - Added multi-species lineage badges and summary indicators to the catalog grid cards.
- **Relevance Rule Evaluation (H4 / R1–R4)**:
  - R1 (Reviewed Swiss-Prot): 4,962 proteins accepted.
  - R2 (Literature cited): 465 proteins accepted.
  - PDB_MAPPED: 199 proteins accepted.
- **Verification Deliverables**:
  - Created `docs/verification/p3_pull_reconciliation_report.json` with per-taxon reconciliation details.

## Decisions Made
- Capped PDB structure fetching for microbial taxa (*Y. pestis* and *Influenza A*) at top 25 high-confidence entries to prevent querying thousands of modern hospital isolates while preserving genuine historical/ancient loci.
- Preserved 100% of ancient proteins across sister species and congeneric taxa (*Smilodon populator*, *Glyptodon sp.*, all moa genera) with granular species attribution.
