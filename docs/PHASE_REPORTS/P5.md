# Phase P5 Report — External Database Expansion & Cross-Reference Ingestion

## Done (with evidence)
- **Database Registry Expanded (§P5.1)**:
  - Registered all target cross-reference databases in `docs/DB_REGISTRY.md`:
    - KEGG REST API & URL template (`https://www.kegg.jp/entry/{identifier}`)
    - InterPro & Pfam REST APIs & URL templates (`https://www.ebi.ac.uk/interpro/entry/...`)
    - NCBI Gene & RefSeq Entrez APIs & URL templates
    - AlphaFold Protein Structure Database API & URL template (`https://alphafold.ebi.ac.uk/entry/{identifier}`)
    - CATH Superfamily API & URL template
  - Each entry documents official documentation, endpoints, regex format, licensing/terms (including academic terms for KEGG per H10), rate limits, and empirical test call with observed status and fields.
- **Relational Cross-Reference Table Populated (§P5.2)**:
  - Extracted authoritative cross-references directly from cached raw UniProtKB entries for all 5,626 staged proteins.
  - Initialized and populated `data/paleo_metadata.db:cross_references` with 101,032 validated cross-reference entries across 10 biological databases.
  - Populated exact fields: `uniprot_accession`, `project_tax_code`, `database`, `identifier`, `url`, `properties_json`, `retrieved_at`, `raw_response_ref`.
- **AlphaFold Predicted Structures Ingested (§P5.3)**:
  - Ingested supplementary AlphaFold DB models per approved human decision H7.
  - Queried AlphaFold DB API (`https://alphafold.ebi.ac.uk/api/prediction/{acc}`) and UniProt cross-references.
  - Stored 355 predicted structure models in `data/paleo_metadata.db:predicted_structures` with explicit `structure_type = "predicted"`, `plddt_score`, `model_url`, and `cif_url`.
  - Experimental crystal structures remain strictly segregated in `protein_structure_mappings` and `staging_structures` (`pdb_id` stays null when no experimental crystal structure exists).
- **Independent Live Regex & Sample Verification (§P5.4)**:
  - Validated all 101,032 records against database-specific identifier regular expressions.
  - Executed random sample verification of 100 cross-references across databases (seed=42).
  - Verified 100 / 100 sample entries (100.0% pass rate). Zero malformed or unreachable URLs.
- **Verification Deliverables**:
  - Verification report generated at `docs/verification/p5_cross_references_verification_report.json`.
  - Machine-readable changelog at `data/changelogs/p5_xref_changelog.jsonl` (101,032 rows).
  - Updated `docs/CHANGELOG_TABLE.md` with P5 rows.
