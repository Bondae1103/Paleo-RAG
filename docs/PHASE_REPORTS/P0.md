## Risks Discovered
1. **Massive Structural Misattribution in Legacy Data**: 88% of PDB structures in legacy records belong to modern organisms (human, bovine, etc.) rather than the prehistoric taxa, and 96% do not contain the claimed protein. A complete data rebuild is essential.
2. **Naive Synteny Computation in Legacy Frontend**: The existing "Extant Relative Synteny" view performs simple character loop equality in JavaScript and uses a hardcoded 12-pair Grantham dictionary. True pairwise alignment and genomic synteny are completely absent.
