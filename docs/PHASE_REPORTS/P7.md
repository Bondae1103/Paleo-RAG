# Phase P7 Report — RAG Ingestion & Grounded Explanations

## Done (with evidence)
- **Document Chunking & Metadata Enrichment (§P7.2)**:
  - Processed all 885 papers in the literature corpus.
  - Parsed 443 open-access papers using `parse_jats_xml()` into structured sections (`Abstract`, `Introduction`, `Methods`, `Results`, `Discussion`, `Table`, `Caption`).
  - Parsed 442 abstract-only papers into `Abstract` blocks.
  - Chunked documents using `chunk_document()` into 6,393 semantic chunks.
  - Attached rich metadata to every chunk: `doc_id`, `chunk_index`, `section`, `chunk_type`, `pmid`, `doi`, `pmcid`, `uniprot_accessions`, `taxon_ids`, `evidence_types`, `license`, and `content_hash`.
- **Dense Embeddings with Hash Caching (§P7.2, H9)**:
  - Enforced approved Decision H9: local-first PubMedBERT dense embeddings (`NeuML/pubmedbert-base-embeddings`, 768 dimensions) with zero external egress.
  - Implemented persistent SQLite hash cache at `data/embedding_cache/pubmedbert_embeddings.db`.
  - Computed and cached 6,393 vectors in batches of 64.
- **Qdrant Storage & In-Process BM25 Synchronization (§P7.2)**:
  - Initialized local persistent Qdrant collection `paleo_chunks` at `./data/qdrant_storage`.
  - Upserted 6,393 points with deterministic UUID5 IDs (`_to_qdrant_point_id("{doc_id}::{chunk_index}")`).
  - Synchronized in-process `BM25SparseIndex` with all 6,393 chunks for Reciprocal Rank Fusion ($k=60$).
- **Strict Generation & Citation Contract (§P7.3)**:
  - Codified prompt contract and code verification:
    - Rule 1: Every factual claim carries an inline citation marker `[doc_id:chunk_index]`.
    - Rule 2: Output split into explicit sections: `### Literature Findings (Cited)` and `### Interpretation & Synthesis`.
    - Rule 3: Exact abstention contract: zero-literature queries return `"No supporting literature found in the corpus for this protein."`
    - Rule 4: Prohibition against claiming adaptations not stated in retrieved chunks.
- **Evaluation Benchmark (§P7.4)**:
  - Designed and executed 23-question evaluation benchmark across extinct taxa and proteins (18 positive paleogenomics questions + 5 negative control / zero-literature abstention cases).
  - Benchmark results:
    - Faithfulness Rate: 18 / 18 (100.0%)
    - Abstention Accuracy: 5 / 5 (100.0%)
    - Citation Precision: 23 / 23 (100.0%)
  - Full evaluation log stored in `docs/verification/p7_rag_evaluation_report.json`.
  - Machine changelog saved in `data/changelogs/p7_rag_changelog.jsonl` (6,393 rows).
